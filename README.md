# 出勤日案内カード

お客様に渡す「出勤日のご案内」カードを作り、A4用紙に並べて印刷するツールです。印刷サイズは「A4で10枚（名刺サイズ 91×55mm）／8枚（97×70mm）／6枚（97×93mm）」から選べます。
`index.html` 1枚で動作します（サーバー・インストール・外部読み込みなし。フォントも端末のものを使用）。

- 要件定義：[要件定義書.md](要件定義書.md)
- 利用者向けの説明：[操作マニュアル.md](操作マニュアル.md)

## 画面構成

- 880px以上：左＝入力、右＝カードの見本（sticky）。未満は縦並び。
- 入力：①年月 ②担当者名・店舗 ③出勤日カレンダー（付ける種類を選んでから日付を押す）④色と他店（他店①は最初からあり、「＋ 他店をもう1店追加」で最大5店）⑤印刷サイズ。
- 見本は印刷と同じ `cardHTML()` の出力を `transform: scale()` で拡大表示（`fitPreview()`）。

## 改修ポイント

`<script>` 冒頭の「設定」ブロックにまとまっています。

| 変数 | 内容 |
|---|---|
| `STORES` | 店舗一覧（13店舗。表示そのまま）。1行追加で増える |
| `COLORS` | 選べる色（`bg`＝塗り、`fg`＝数字の色）。黄など明るい色は `fg` を濃くする |
| `LAYOUTS` / `LAYOUT_ORDER` | 印刷サイズ。`cols`×`rows` 枚、1枚 `w`×`h` mm、`k`＝文字・余白の拡大率。行を足せば選択肢が増える（`rows*h` が297mm以下になるように） |
| `NEXT_MONTH_FROM_DAY` | この日以降に開くと翌月を初期表示（20） |
| `MAX_OTHERS` / `OTHER_DEFAULT_COLORS` | 他店の最大数（5）と、追加時に割り当てる色の順。当店＋他店の数は `COLORS`（8色）以下にすること |

カードの固定文言（タイトル・「またのご相談を…」・注意書き）は `cardHTML()` 内に直接書いています。

## データの持ち方

- `state.marks`：`"y-m-d"` → `"own" | "o1"〜"o5"`。日付キーなので月を切り替えても他の月の印と混ざらない。表示・判定は `monthMarks()` で「選択中の月」かつ「有効な種類」だけを取り出す。
- 他店は `state.others`（使用中の id の並び）と `state.kinds[id]`（`{ color, store }`）で持つ。`addOther()` は空いている id とまだ使っていない色を割り当て、`removeOther(id)` はその他店の印を全月分削除する（画面に件数を表示）。
- 画面の「他店①②…」の番号は id ではなく `state.others` の並び順（`kindLabel()`）。途中の他店を消すと番号が詰まる。他店が1店だけのときは削除ボタンを出さない。
- **保存は一切しない**（localStorage 等も不使用）。再読み込みで全消去。

## フェイルセーフ

判定は `problems()` に一本化し、画面のメッセージ・「印刷する」ボタン・印刷時の表示切り替えの全部で使います。

- 印刷ブロック（エラー）：担当者名が空／店舗未選択／その月の印が0日／他店に当店と同じ店舗／他店どうしで同じ店舗／種類どうしで同じ色。
- 要確認（警告のみ）：他店の印があるのに店名が空欄（カードには「他店」と出る）／店名空欄の他店が2つ以上使われている（カード上は色でしか区別できない）。
- エラー中は `body.blocked` が付き、Ctrl+P で印刷してもカードの代わりに「印刷できません：理由」が印刷される。
- 白黒印刷対策：当店＝○（円）、他店＝□（角丸四角）と形を変えている。

## 印刷

- `@page { size: A4 portrait; margin: 0 }`。`.print-sheet` のグリッド（列数・カード幅・行の高さ・上余白）は `applySheetLayout()` が `LAYOUTS` から設定し、左右は中央寄せ。切り取り線は各カードの `outline` 破線。
- カードの大きさは CSS 変数 `--w` / `--h`、文字や余白は `--k` 倍（`cardHTML()` がカードの style に入れる）。カレンダーは CSS grid（`--weeks` 行・各行 `1fr`）で、残りの高さを週の数で等分する。大きいサイズほどマスが高くなる。
- カードの色の説明は「●の付いた日が出勤日です。」の後ろに「■＝店名」を続けて並べ、折り返す（`.c-note` 内の span）。表記は店名のみ（「〜で出勤」は付けない）。説明に出るのは、その月に印がある他店だけ。
- 10枚のときは高さに余裕がないため、カード内の行間を `line-height: 1.3`（マス内は1）に詰め、○□はマスの高さの92%までに縮める。6週ある月＋長い店名の他店5店でも、3サイズすべて収まることを確認済み。
- 色は `print-color-adjust: exact` で出す。ブラウザ側で「背景のグラフィック」がオフでも Chrome/Edge では印刷されるが、環境によってはオンが必要。
- ブラウザの印刷設定で倍率が100%以外・余白ありになると名刺サイズからずれる（操作マニュアルで案内）。
- 確認方法：Edge のヘッドレス印刷（`msedge --headless --print-to-pdf=out.pdf index.html`）で、10枚・8枚・6枚それぞれA4 1ページに収まることを確認済み（入力済みの状態にしたテスト用コピーで実施）。

## 既知の制約

- 祝日は判定しない（日曜＝赤、土曜＝青のみ）。
- 1枚の用紙のカードはすべて同じ内容。担当者ごとに分けたい場合は、1人ずつ印刷する。
- 年月は「先月〜3ヶ月先」の5択。
- `meta robots noindex` のため検索には出ない。URLを共有して使う。
