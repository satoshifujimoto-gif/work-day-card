# 出勤日案内カード

お客様に渡す「出勤日のご案内」カード（名刺サイズ 91×55mm）を作り、A4用紙に10枚（2列×5段）並べて印刷するツールです。
`index.html` 1枚で動作します（サーバー・インストール・外部読み込みなし。フォントも端末のものを使用）。

- 要件定義：[要件定義書.md](要件定義書.md)
- 利用者向けの説明：[操作マニュアル.md](操作マニュアル.md)

## 画面構成

- 880px以上：左＝入力、右＝カードの見本（sticky）。未満は縦並び。
- 入力：①年月 ②担当者名・店舗 ③出勤日カレンダー（付ける種類を選んでから日付を押す）④色と他店（他店①、追加で他店②）。
- 見本は印刷と同じ `cardHTML()` の出力を `transform: scale()` で拡大表示（`fitPreview()`）。

## 改修ポイント

`<script>` 冒頭の「設定」ブロックにまとまっています。

| 変数 | 内容 |
|---|---|
| `STORES` | 店舗一覧（13店舗。表示そのまま）。1行追加で増える |
| `COLORS` | 選べる色（`bg`＝塗り、`fg`＝数字の色）。黄など明るい色は `fg` を濃くする |
| `CARDS_PER_SHEET` | 1枚に並べる数（10。変える場合は印刷CSSの段数・余白も調整） |
| `NEXT_MONTH_FROM_DAY` | この日以降に開くと翌月を初期表示（20） |

カードの固定文言（タイトル・「またのご相談を…」・注意書き）は `cardHTML()` 内に直接書いています。

## データの持ち方

- `state.marks`：`"y-m-d"` → `"own" | "o1" | "o2"`。日付キーなので月を切り替えても他の月の印と混ざらない。表示・判定は `monthMarks()` で「選択中の月」かつ「有効な種類」だけを取り出す。
- 他店②を削除すると、他店②の印は全月分削除（画面に件数を表示）。
- **保存は一切しない**（localStorage 等も不使用）。再読み込みで全消去。

## フェイルセーフ

判定は `problems()` に一本化し、画面のメッセージ・「印刷する」ボタン・印刷時の表示切り替えの全部で使います。

- 印刷ブロック（エラー）：担当者名が空／店舗未選択／その月の印が0日／他店に当店と同じ店舗／他店①②が同じ店舗／種類どうしで同じ色。
- 要確認（警告のみ）：他店の印があるのに店名が空欄（カードには「他店で出勤」と出る）／他店②だけ使用。
- エラー中は `body.blocked` が付き、Ctrl+P で印刷してもカードの代わりに「印刷できません：理由」が印刷される。
- 白黒印刷対策：当店＝○（円）、他店＝□（角丸四角）と形を変えている。

## 印刷

- `@page { size: A4 portrait; margin: 0 }`、`.print-sheet` を 91mm×2列・55mm行のグリッドで中央寄せ（左右14mm・上11mm）。切り取り線は各カードの `outline` 破線。
- 色は `print-color-adjust: exact` で出す。ブラウザ側で「背景のグラフィック」がオフでも Chrome/Edge では印刷されるが、環境によってはオンが必要。
- ブラウザの印刷設定で倍率が100%以外・余白ありになると名刺サイズからずれる（操作マニュアルで案内）。
- 確認方法：Edge のヘッドレス印刷（`msedge --headless --print-to-pdf=out.pdf index.html`）でA4 1ページ・10面になることを確認済み。

## 既知の制約

- 祝日は判定しない（日曜＝赤、土曜＝青のみ）。
- 10枚とも同じ内容。担当者ごとに分けたい場合は、1人ずつ印刷する。
- 年月は「先月〜3ヶ月先」の5択。
- `meta robots noindex` のため検索には出ない。URLを共有して使う。
